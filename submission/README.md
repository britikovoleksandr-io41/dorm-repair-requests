## Підготовка до DEFENSE

Студент заповнює окрему сторінку для кожної ЛР і погоджує чернетку spec та ADR. На сторінці потрібні мета у 1–2 реченнях, три власні аудиторські висновки з ревізіями або статусом, рішення й альтернативи з ADR, відтворювана команда і фактичний результат. Для ЛР1–ЛР3 вказати Git SHA. Для ЛР4–ЛР5 додати SHA з `/version` разом із середовищем, у якому його отримано.

Окремий повний Definition of Done викладача та шаблон DEFENSE у доступних матеріалах курсу відсутні. Перед здачею потрібно звірити пакет із цими матеріалами.
