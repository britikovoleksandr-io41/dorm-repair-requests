# ЛР1 · Основа застосунку

**Мета** — підготувати HTTP-процес і повторювані локальні перевірки для наступних ЛР.

**Статус** — чернетка для погодження студентом. Вибір Node.js без HTTP-фреймворку, шлях встановлення hooks і мінімальний обсяг smoke є робочими рішеннями. [ADR](../adr/0000-foundation.md).

## Критерії приймання

1. Після `npm ci` команда `npm run check` завершується з кодом 0. Вона перевіряє Prettier, ESLint, збірку та HTTP smoke.
2. Зібраний процес відповідає `200` на `GET /health` і `404` на невідомий маршрут. Smoke запускається без БД.
3. Після `npm run hooks:install` pre-commit перевіряє staged-зріз, а pre-push — дерево переданого SHA. Мінімум один явно позначений негативний коміт відхиляється. Для pre-push чисте дерево проходить, а неформатований SHA дає ненульовий код при локальному виклику hook.
4. У `standards/` доступні формат специфікації, формат MADR і робочий Definition of Done. Накопичувальна специфікація містить ролі, дозволені переходи, модулі та зв’язок заявки з історією.
