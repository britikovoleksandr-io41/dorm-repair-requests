# Робочий Definition of Done

- Поведінка відповідає погодженій специфікації, а помилки описані й перевірені.
- `npm ci`, `npm run check` і перевірки етапу проходять з чистого checkout.
- Коміти Conventional Commits зберігають працездатні межі. Для вимірів і перевірок є команда, фактичний результат і версія коду.
- Студент погоджує робочі пропозиції та власноруч готує DEFENSE. Для здачі застосовується повний Definition of Done викладача.
