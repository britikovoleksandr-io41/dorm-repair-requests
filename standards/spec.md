# Специфікація

Опишіть учасників, їхню мету й зовнішній інтерфейс. Для кожного запису даних назвіть власника, ключі, обмеження та допустимі зміни. Для критичної операції опишіть успіх, конкурентний виклик і відмову джерела даних. Межі модулів покажіть напрямком викликів. Зміна API або інваріанта потребує оновлення специфікації та перевірки.
